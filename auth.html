Что происходит при входе

  • Первый вход (регистрация): Firebase Auth создаёт запись в Authentication (если её ещё нет). На нашем сайте в базе данных появляется запись roles/{uid} с ролью. Самый первый пользователь получает роль admin, остальные — viewer.
  • Последующие входы: запись в Authentication обновляется (поле lastSignInTime). В базе данных ничего нового не создаётся — роль подгружается из существующего узла roles/{uid}.
  • В этой же сессии 역할 определяет, кто может удалять записи студентов (только admin).
